插件开发与使用（API v1） ​

产品形态 ​

一个扩展包可同时包含页面和操作。页面是顶部或左右侧 Tab 中的 HTML iframe，布局、表单、画布等由 HTML 自己实现。操作是独立 JS 入口，注册命令后可出现在顶部按钮、场景或组件右键菜单，以及扩展管理中的命令列表；执行不依赖页面是否打开。

扩展管理位于工作台顶部的独立拼图图标入口，采用 EDA 的列表、详情、元信息分栏。页签为“外部扩展 / 已安装”。外部插件源当前显示“暂未接入插件源”，不会访问 GitHub 或其他远端市场。

ThoughtLab 仍是独立实验设计。本期没有搬入其业务代码，也没有把它假装成已安装插件。

用户使用 ​

  1. 点击顶部“扩展管理”图标，在弹窗中点击“导入”，选择 .jlcext 或 .zip。
  2. 选择后直接安装，同 ID 的新包直接更新；完成后通过吐司提示成功或失败。名称、版本、作者和权限可在扩展详情查看。
  3. 在“已安装”中查看详情、更改日志、启停、卸载，或打开页面、执行命令。
  4. 页面和命令统一从独立的“扩展管理 → 已安装”的扩展详情打开。声明 toolbar 的命令会成为顶部按钮。

页面默认复用同一 Tab；声明 singleton: false 可打开多份。关闭 Tab 会销毁 iframe。页面身份及当前选中项会保存在个人偏好，下次打开工作台尝试恢复；插件内部数据应使用自己的 storage。

禁用、卸载或更新会关闭本窗口中该插件的页面和操作运行环境，并撤销旧 API 会话。已发出的外部操作无法撤销，不应把禁用当成回滚。卸载保留独立存储，重装同 ID 可继续读取。

包格式 ​

ZIP 根目录必须有 jlc-extension.json，不要再套一层项目文件夹。文件最大 8 MB，解压合计最大 32 MB，最多 512 个归档条目；拒绝越界路径、符号链接、重名与 Windows 保留文件名。

json
{
  "schemaVersion": 1,
  "id": "myteam.my-tool",
  "name": "我的工具",
  "version": "1.0.0",
  "description": "工具说明",
  "author": "作者",
  "license": "MIT",
  "permissions": ["storage", "scenes.read"],
  "keywords": ["工具"],
  "readme": "README.md",
  "changelog": "CHANGELOG.md",
  "pages": [{"id": "main", "title": "我的工具", "entry": "index.html", "singleton": true}],
  "commands": [{"id": "count", "title": "统计场景", "entry": "commands.js", "placements": ["toolbar", "scene-context", "command"]}]
}

pages 和 commands 至少有一种。页面入口以 .html 结尾，命令入口以 .js 结尾。每组 ID 唯一；命令位置支持 toolbar、scene-context、component-context、command。操作脚本使用普通浏览器脚本，在顶层同步注册处理器，在处理器内部执行异步业务。

icon 可选，填写包内 PNG/JPG/WebP 路径，最大 256 KB；没有图标显示扩展默认图标。详情文档以安全文本和基本 Markdown 标题显示，不执行文档内 HTML。

打包示例：

powershell
python -X utf8 -m world_api_sdk pack examples/hello-extension --output dist/hello-extension.jlcext

该命令会先校验清单，不安装插件、不读取工作台用户数据。可复制 examples/hello-extension 开始开发。若使用 React/Vue 等构建工具，应将构建产物和清单放在包根目录，资源路径使用相对路径，不依赖根路径 /assets/。

左右侧 Tab ​

页面入口可以声明 placement: "left" 或 "right"，扩展启用后自动注册到对应侧栏；省略时为顶部 "tab"。侧栏每个页面只有一个实例，不受 singleton:false 影响。

json
"pages": [
  {"id":"outline","title":"大纲","entry":"outline.html","placement":"left"},
  {"id":"inspector","title":"扩展属性","entry":"inspector.html","placement":"right"}
]

也可在本扩展页面或命令中动态注册清单中已有的页面：

js
await workbench.pages.registerSidebar({pageId:'inspector',side:'right'});
await workbench.pages.registerSidebar({pageId:'inspector',side:'left'}); // 复用实例并换边
await workbench.pages.unregisterSidebar({pageId:'inspector'});
await workbench.pages.open({pageId:'inspector',placement:'tab'}); // 转为顶部页面

重复注册复用同一实例。侧栏 Tab 继承工作台的收起、展开、拖动换边、浮动和位置偏好；侧栏关闭按钮收起面板，unregisterSidebar 则销毁侧栏实例。侧栏不会占用或遮盖中央原型/浏览器 Tab。支持 moveBefore 的浏览器在同窗口换边时保留 iframe 状态；跨原生窗口会重载 iframe，需持久化的数据应写入扩展 storage。未指定位置重新打开时沿用用户偏好；显式 API 注册可重新指定左右侧。动态注册会随已打开页面恢复；清单声明的侧栏在扩展启用或目录刷新时重新注册。

新方法只能操作本扩展清单内的页面，无需额外权限。禁用、卸载或更新扩展时会清理全部侧栏、顶部页面和对应 API 会话。

页面与操作 SDK ​

工作台自动在 HTML 文档的 head 开头注入 SDK；没有 head 时前置注入。不要在包内提供 _sdk.js，该路径及 __command__/ 为宿主保留。无需传入服务 token，也不要引用工作台内部全局变量或 DOM。

javascript
// 页面中使用 Promise API。
const oldValue = await workbench.storage.get({key: 'draft'});
await workbench.storage.set({key: 'draft', value: {text: '内容'}});
const context = await workbench.app.getContext();
await workbench.ui.showToast({message: '已完成'});
await workbench.pages.open({pageId: 'main'}); // 只能打开本插件声明的页面
javascript
// commands.js：页面没有打开时，也可独立执行。
workbench.commands.register('count', async context => {
  const result = await workbench.scenes.list({limit: 1});
  await workbench.ui.showToast({message: `本地场景：${result.total}`});
  return {total: result.total};
});

context 提供 sessionId、sceneId、nodeId；组件右键命令还提供 componentId。没有选中目标时对应字段为 null，不应自行猜测目标。命令开始时捕获上下文，切换工作台选择不会把正在执行的命令悄悄改到另一个目标。

同一命令执行中禁止再次启动。命令完成、异常、超时、禁用或卸载后销毁隐藏 iframe；默认超时为 120 秒。Agent 命令在启动、轮询或取消任务时续期此计时，agent.run() 会自动轮询。长任务应向用户反馈进度。页面加载超过 15 秒在 Tab 内提示，不弹系统模态框。

API 和权限 ​

所有方法也可用 workbench.call('方法名', params) 调用。没有声明的权限会被服务端拒绝，前端按钮显隐不是授权依据。

SDK 按对象分组，后端每组对应一个服务类，通过 @method 同时注册方法和权限；ExtensionAPI 统一分发，原有方法名称和参数保持兼容。调用 await workbench.app.describe() 可获取当前方法、所属组、所需权限及是否可用。

调用内置 Agent ​

由扩展自行编排工作流时使用 Agent 单轮对话 的 agent.chat() / startTurn()。以下 run() / start() 示例使用内置自主执行循环。

清单声明 "permissions": ["agent.invoke"]，直接使用工作台当前模型，或用 profile 指定 agent.models() 返回的配置 ID。模型密钥和接口地址不会返回给扩展。

js
const controller = new AbortController();
const completed = await workbench.agent.run({
  prompt: '根据这些需求整理导入流程，输出建议。',
  context: { requirements: ['支持多选', '失败时允许重试'] },
  signal: controller.signal,
  onEvent(event) {
    if (event.kind === 'delta') appendText(event.text);
    if (event.kind === 'plan') renderPlan(event.plan);
    if (event.kind === 'tool') showProgress(event.name);
  }
});
console.log(completed.result, completed.conversationId);
// 后续明确续聊；不传 conversationId 就是一个独立的新会话。
await workbench.agent.run({prompt: '补充失败处理', conversationId: completed.conversationId});
// 运行中调用 controller.abort() 即可停止相应任务。
  • 状态为 running / complete / failed / cancelled。事件含 seq，类型包括 delta / message / tool / tool-result / plan / context。delta 用于即时文本展示，message 和最终 result 用于完整结果，不应将两者重复拼接。
  • 也可自行调用 start / poll / cancel：初始 cursor=0，每次用返回的 cursor 继续；每批最多 200 个事件，有待取事件时仍返回 running，避免提前停止漏掉结果。
  • 共用工作台的 Agent 执行循环、计划、工具错误反馈、上下文压缩及完整工具结果归档。任务不会进入主工作台的 AI 对话，也不会自动读取其他 Tab 的上下文。prompt 最多 8000 字，显式 context 最多 100000 字符。
  • Agent 只能通过当前扩展已声明的 storage / scenes / components / window API 使用工具。例如要让 Agent 读取场景，需同时声明 agent.invoke 和 scenes.read。没有窗口权限就不能借 Agent 操作窗口；Agent 不能再启动另一个 Agent，也不能读取模型密钥。
  • 任务和会话归属发起调用的扩展运行页面/命令。其他扩展及同扩展的其他页面实例不能查询或取消该任务，也不能续接该会话。关闭页面、禁用、卸载、更新扩展会取消仍在执行的任务。
  • 同一会话同时只允许一个运行任务；扩展 Agent 合计最多 4 个并行任务，内存保留最近最多 64 个任务，会话不承诺跨工作台重启续接。失败/取消后新建会话重试，避免带入不完整工具交互。
  • 已提供可打包示例 examples/agent-assistant/。后端分组在 creator/extension_api.py，Agent 服务在 creator/extension_agent.py，浏览器 SDK 在 creator/extension-sdk.js。

storage 是每插件独立的本地 JSON 键值存储，不设置固定容量配额；存储使用本机可用磁盘和内存。GIF、MP4、HTML 等内容可转为 Base64 或文本后保存，不会被宿主自动压缩或转码。浏览器 JS、DOM、Canvas、定时器、文件选择、Blob 下载可在 iframe 内正常使用；直接访问父页面、任意本机文件、原生模块不属于浏览器能力。

network 权限允许插件自行使用 HTTP(S)/WebSocket（仍受目标服务器 CORS 约束）；没有该权限时连接由 CSP 禁止。授予联网、资源写入或目标执行权限前应检查来源和代码。

运行与兼容边界 ​

  • iframe 使用脚本/下载沙箱，不授予 same-origin；通过消息来源绑定和可撤销会话桥调用 API。
  • 插件资源地址只含此插件的资源能力，不携带主服务 token；资源能力不能作为主 API 的登录凭证。
  • 插件写入权限允许执行对应资源的修改，删除/批量操作前应由插件自行设计用户确认。
  • 左右侧扩展已接入工作台停靠系统；顶部扩展页面不支持直接拖动浮出，可通过 API 转为侧栏。远端市场与插件后台常驻服务尚未接入。
  • 插件资料保存在用户数据目录的 extensions/，不写回安装目录。工作台全量程序更新不会覆盖用户插件。
