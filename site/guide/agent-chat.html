Agent 原子单轮对话 ​

扩展声明 agent.invoke 权限。workbench.agent.chat() 复用工作台已保存的模型配置，直接执行一次模型采样；不进入 AgentRuntime，不创建任务计划、不执行工具、不压缩或保存会话、不读取其他 Tab 上下文。模型协议适配及不兼容参数修正仍由宿主负责；不自动追加模型轮次。

与之对应，agent.run() / agent.start() 仍是内置 Agent 自主执行任务的接口，保留原来的计划和工具循环。

直接调用 ​

js
const controller = new AbortController();
const result = await workbench.agent.chat({
  // 不传 profile 则使用工作台当前模型；agent.models() 可列出公开配置 ID。
  messages: [
    { role: 'system', content: '你是我的工作流助手。只输出 JSON。' },
    { role: 'user', content: '把任务拆成三个步骤' }
  ],
  signal: controller.signal,
  onEvent(event) {
    if (event.kind === 'delta') console.log(event.text);
  }
});
console.log(result.response.message.content); // 模型文本原样返回，不把 JSON 当作宿主指令
console.log(result.response.usage); // 供应商有返回用量时提供，否则 null

result.result 同时提供完整文本。response.message 是可追加到下一次 messages 的 assistant 消息；response.toolCalls 提供 {id, name, arguments} 数组，arguments 是模型返回的 JSON 字符串。支持 Chat Completions 和 Responses 配置。工具仅支持原生函数协议，不会回退为宿主注入的文本工具提示词。

调用方编排工具 ​

js
const messages = [{ role: 'user', content: '给我当前草稿的摘要' }];
const tools = [{ type: 'function', function: {
  name: 'read_draft', description: '读取扩展自己的草稿',
  parameters: { type: 'object', properties: {}, additionalProperties: false }
}}];
const first = await workbench.agent.chat({ messages, tools });
messages.push(first.response.message);
for (const call of first.response.toolCalls) {
  if (call.name !== 'read_draft') throw Error('未知工具');
  JSON.parse(call.arguments || '{}'); // 自行校验工具参数和权限
  const draft = await readMyDraft(); // 扩展自己实现；宿主不会替你执行
  messages.push({ role: 'tool', tool_call_id: call.id, content: JSON.stringify(draft) });
}
if (first.response.toolCalls.length) {
  const second = await workbench.agent.chat({ messages, tools });
  console.log(second.response.message.content);
}

每次 chat() 都是独立的一轮。继续调用、并行调度、循环条件、预算和工具执行由扩展负责。response.message.providerState 若存在，是 Responses 模型的透明续接数据；原样保留在 assistant 消息中，不修改内部字段，续接时保持同一模型配置。它不包含接口地址或密钥。

手动控制和边界 ​

  • agent.startTurn({messages, profile?, tools?}) 立即返回句柄；通过 agent.poll({id,cursor}) 读取事件和最终 response，通过 agent.cancel({id}) 取消。只有完整成功结果包含 response，失败或取消不能当成完成。
  • chat() 的 onEvent 接收 delta、tool-call 和最终 message；最终 message 是完整文本，避免与 delta 重复拼接。
  • 不接收 conversationId，不自动承接历史；所有上下文都由 messages 显式传入。输入消息和工具的 JSON 合计最多 1000000 字符，超限明确报错，不静默截断。
  • 同页能力凭证隔离，关闭扩展页面或撤销扩展权限会停止任务；跨扩展和同扩展的其他页面不能读取任务。与自主执行接口合计最多 4 个并行任务，内存最多保留 64 个任务。
  • 取消会及时停止轮询和结果写入；已经发出的供应商网络请求可能稍后才结束。模型凭证始终由宿主管理，不向扩展返回。
