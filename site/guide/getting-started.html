快速开始 ​

创建扩展 ​

sh
git clone https://github.com/EsayEDA-Product-Team/World-Api-Sdk.git
cd World-Api-Sdk
python -X utf8 -m world_api_sdk init ../my-extension --id com.example.my-tool --name 我的工具
python -X utf8 -m world_api_sdk pack ../my-extension --output dist/my-tool.jlcext

在工作台“扩展”中导入生成的包。运行时宿主自动注入 workbench，不要把 _sdk.js 或 browser/host-sdk.js 放进插件。

同步最新 API ​

已 clone 的 SDK 需要更新类、类型声明和接口文档时，在 SDK 目录执行 npm run sync，或 python -X utf8 -m world_api_sdk sync。不需要安装文档构建依赖；复用 GitHub 的 Git 登录权限。详细行为见本体 → SDK 自动同步。

类型与类 ​

ts
import { getWorkbench } from '@jlc-world/api-sdk';
import type { Workbench, AgentEvent } from '@jlc-world/api-sdk';
const api: Workbench = getWorkbench();
await api.storage.set({ key: 'draft', value: { title: '我的草稿' } });

导出的 API 类可用于类型提示或封装，实际调用委托给宿主已经注入的桥；导入 SDK 不会安装第二套消息桥。

调整工作台布局、页面和样式 ​

清单按需声明 ui.layout 和 ui.styles。layout.get() 返回内置面板、已打开插件页签、浮窗坐标及侧栏状态，styles.targets() 返回可覆盖的区域。布局方案的持久保存与恢复见 布局方案。

ts
await api.layout.movePanel({ panel: 'ai', placement: 'left' });
await api.layout.setSidebarWidth({ side: 'left', width: 380 });

const key = await api.pages.open({ pageId: 'main' });
await api.pages.move({ key, placement: 'right' });
await api.pages.rename({ key, title: '项目面板' });
await api.pages.configureInstance({ key, width: 680, height: 480, showFloatButton: false });

await api.styles.set({
  id: 'compact-ai',
  target: 'creator.ai',
  css: `
    :scope { gap: 6px; }
    .ai-message { padding: 6px 8px; }
    @media (max-width: 1100px) { .ai-message { font-size: 13px; } }
  `,
});

预览页可以在 pages.open({ pageId: 'preview', placement: 'float', showFloatButton: false, closeBehavior: 'close' }) 时隐藏双框图标，并让标题栏 × 直接关闭页面实例。运行中可通过 pages.configureInstance() 更新选项。再次打开时，页面会创建新的实例，插件可通过存储接口还原所需的状态。

pages.listOpen() 查询本扩展的页面实例。pages.focus() 和 pages.closeInstance() 也按 key 操作。扩展页面内部沿用自己的 HTML、CSS 和 JavaScript；替换工作台某个区域的整块界面用 ui.compose()。

样式直接传 CSS 源码，:scope 指目标区域自身，普通选择器作用于该区域的后代。相同 id 更新本扩展已有的覆盖。支持 !important 和条件规则，加载资源的函数和全局规则会被拒绝。需要支持 @scope 的 WebView2，宿主内部选择器可能随界面更新。 W3C CSS @scope

workbench.toolbar 是创造模式与脚本模式共用的顶部全局工具栏。嵌入的嘉立创 EDA 页面使用自身的样式。

ts
await api.styles.set({
  id: 'dark-toolbar',
  target: 'workbench.toolbar',
  css: ':scope { background: #1c232d; color: #eef2f7; } button { background: #293443; color: #eef2f7; }',
});

样式与栏宽覆盖在本窗口生效。用 styles.remove({ id })、styles.clear() 或 setSidebarWidth({ side, width: null }) 撤销。扩展更新、禁用、卸载或窗口重载会清理覆盖；用户也可以在扩展管理中恢复样式与栏宽。调整停靠、浮窗尺寸或侧栏折叠会使用工作台现有的布局保存机制。

浏览本地目录 ​

清单声明 files.localRead 后，可让用户通过系统对话框为扩展选一个目录。选择会保存到下次启动，取消时保留原目录。列表与文件路径都相对于所选目录。

js
const directory = await api.files.selectDirectory();
if (directory) {
  const entries = await api.files.listDirectory();
  console.log(directory.name, entries);
}

files.getDirectory() 返回已选择的目录。files.listDirectory({ path: '设计/原型' }) 只列出该级的内容。files.localFileUrl({ path }) 返回文件 URL，可用 browser.openTab() 预览，需声明 browser.open。files.showInFolder({ path }) 通过系统资源管理器打开文件所在目录。

调用 Agent ​

清单加入 agent.invoke，并先在工作台配置模型：

ts
const controller = new AbortController();
const completed = await api.agent.run({
  prompt: '分析这些需求',
  context: { requirements: ['支持批量导入'] },
  signal: controller.signal,
  onEvent(event: AgentEvent) {
    if (event.kind === 'delta') console.log(event.text);
  }
});
console.log(completed.result);

查找方法 ​

使用左侧 API 类导航，或按 Ctrl+K 搜索类名、方法名和描述。比如 AgentAPI 包含任务启动、查询、取消和自动轮询。

自定义扩展和命令图标 ​

在包根目录 jlc-extension.json 使用扩展级 icon 设置默认图标；命令可用自己的 icon 覆盖，顶部快捷入口和右键菜单都会显示。未指定命令图标时继承扩展图标，两者都未配置时使用宿主默认图标。

json
{
  "schemaVersion": 1,
  "id": "example.tools",
  "name": "示例工具",
  "version": "1.0.0",
  "icon": "assets/plugin.png",
  "commands": [
    {
      "id": "open",
      "title": "打开工具",
      "entry": "commands.js",
      "icon": "assets/open.png",
      "placements": ["toolbar", "scene-context", "command"]
    }
  ]
}

图片必须随扩展包一起提供，使用包内相对路径；支持 PNG、JPG、JPEG、WebP，每张不超过 256 KB，不支持外部 URL 或 SVG。建议使用透明背景的方形图片；快捷按钮和右键菜单按 20×20 CSS 像素等比显示。SDK 的 validate / pack 与宿主导入使用相同校验规则。扩展管理列表和详情使用扩展级图标。
