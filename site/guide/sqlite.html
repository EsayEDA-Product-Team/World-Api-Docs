扩展 SQLite 数据库 ​

在扩展清单 permissions 中声明 storage.sqlite。生产环境使用宿主注入的 workbench.sqlite，无需额外数据库安装，不读取工作台现有 JSON 数据。

js
const db = await workbench.sqlite.open({name: 'library'});
try {
  await db.migrate({version: 1, statements: [{
    sql: 'CREATE TABLE items (id INTEGER PRIMARY KEY, name TEXT NOT NULL, data BLOB)'
  }]});
  await db.execute('INSERT INTO items (name) VALUES (?)', ['示例组件']);
  const rows = await db.query('SELECT id, name FROM items ORDER BY id LIMIT ?', [100]);
  console.log(rows, await db.info());
} finally {
  await db.close();
}

接口 ​

  • workbench.sqlite.open({name, timeoutMs?})：返回 SQLiteDatabase。
  • workbench.sqlite.list()：列出本扩展数据库名称及占用字节数。
  • workbench.sqlite.remove({name, timeoutMs?})：删除数据库；仍有打开句柄时拒绝删除，调用前由扩展让用户确认。
  • db.query(sql, params?, options?)：只读查询，返回记录数组；重复列名用 AS 区分。
  • db.execute(sql, params?, options?)：单条建表或写入，返回 {changes, lastInsertId}。
  • db.batch(statements, options?)：多条建表或写入，同一事务，返回每条结果；任一步失败整批回滚。
  • db.migrate({version, statements, timeoutMs?})：表结构和版本号原子提交，同版本不重复执行，降级拒绝，返回 {version, applied}。
  • db.info(options?)：返回 {name, version, bytes, tables}；磁盘占用包含当前 WAL/SHM 文件。
  • db.close()：关闭当前句柄，不删除文件。
  • db.virtualTableModules(options?)：探测当前运行时可安全开放的模块，返回 {fts5, rtree}。
  • db.createVirtualTable({name, module, columns, ifNotExists?, timeoutMs?})：原子创建白名单虚拟表，返回 {name, module, created}。
  • db.dropVirtualTable({name, ifExists?, timeoutMs?})：原子删除虚拟表和影子表；不接受普通表，返回是否删除。

statements 为非空 {sql, params?}[]，每项只能有一条 SQL。options 为 {timeoutMs?}，默认 10 秒，可设为 1–60000 毫秒，包含等待同库锁的时间。超时拒绝 Promise，未提交事务回滚。查询结果需在 SQL 中分页；不设置固定容量配额，受本机磁盘和内存限制。

数据类型 ​

绑定参数支持数组或命名对象，值支持 null、字符串、布尔值、有限且在 JS 安全范围内的数字。布尔值以 SQLite 整数 0/1 存储和返回。

js
await db.execute('INSERT INTO items (id, name, data) VALUES (:id, :name, :data)', {
  id: {type: 'integer', value: '9223372036854775807'},
  name: '二进制示例',
  data: {type: 'blob', base64: 'AAEC'}
});

大整数范围是 SQLite 的有符号 64 位整数，使用 {type:'integer', value:'十进制字符串'}。BLOB 使用 {type:'blob', base64:'纯Base64'}。查询返回时采用相同封装；安全范围内的整数返回普通数字。lastInsertId 也遵循此规则，非 INSERT 语句返回 null；changes 包含触发器影响行数。不接受 SELECT/RETURNING 写入结果，使用独立 query 查询。

隔离与生命周期 ​

数据库由工作台保存在用户数据目录 extensions/sqlite/<扩展ID>/<数据库名>.sqlite3。数据库名统一小写，允许 1–64 位英文字母、数字、下划线和短横线；不接受路径和 Windows 保留名称。句柄绑定启动它的扩展会话，不能在其他页面或命令会话中复用。其他会话需要自行 open；同一会话重复 open 同名库复用句柄。

数据库使用 WAL，每次操作建立受限连接，同库操作串行化，在后台 HTTP 工作线程执行。禁止 ATTACH、DETACH、设置 PRAGMA、手动事务控制、临时表及原生扩展，不保留跨调用连接状态。虚拟表使用下述封装接口创建和删除，普通 SQL 仍不能 CREATE/DROP 虚拟表。FTS5 库仅额外允许只读 data_version PRAGMA 供模块内部同步；RTree 创建期间宿主仅允许其读取 page_size，扩展普通 SQL 无此权限。内部版本表受作者化策略保护，普通 SQL 无法读写。使用参数绑定，不将用户输入直接拼入 SQL。

关闭页面、禁用、卸载或更新扩展会撤销句柄。数据保留供下次安装或打开使用，不在升级和卸载时自动删除。需要清除时先关闭所有会话句柄，再由用户明确选择删除数据库。

SDK 的 SQLiteDatabase 是正式返回对象类，公开源码通过 @apiGroup sqlite 标记后生成类、类型、API 清单及文档，流水线验证其每个宿主方法的实现和权限一致性。

FTS5 全文搜索与 RTree 空间索引 ​

仍使用 storage.sqlite 权限。宿主实际创建内存探测表，确认内置模块和 SQLite defensive 模式可用；不支持时返回 false，创建接口会明确报错，不下载或动态加载模块。

js
const modules = await db.virtualTableModules();
if (modules.fts5) {
  await db.createVirtualTable({
    name: 'documents', module: 'fts5', columns: ['title', 'body'], ifNotExists: true
  });
  await db.execute('INSERT INTO documents (title, body) VALUES (?, ?)',
    ['SQLite guide', 'Local searchable documents']);
  const hits = await db.query(
    `SELECT rowid, title, bm25(documents) AS score,
      snippet(documents, 1, '[', ']', '…', 12) AS excerpt
     FROM documents WHERE documents MATCH ? ORDER BY score LIMIT ?`,
    ['searchable', 20]
  );
  console.log(hits);
}
if (modules.rtree) {
  await db.createVirtualTable({
    name: 'regions', module: 'rtree',
    columns: ['id', 'min_x', 'max_x', 'min_y', 'max_y'], ifNotExists: true
  });
  await db.execute('INSERT INTO regions VALUES (?, ?, ?, ?, ?)', [1, 0, 100, 0, 50]);
  const regions = await db.query(
    'SELECT id FROM regions WHERE min_x <= ? AND max_x >= ? AND min_y <= ? AND max_y >= ?',
    [20, 20, 10, 10]
  );
  console.log(regions);
}

表名和列名统一小写，仅允许 1–64 位 ASCII 字母、数字、下划线，不能以数字开头或使用 sqlite_、__world_ 前缀。列名不能重复或与表同名。FTS5 使用默认 unicode61 分词，列为文本；不允许 rank、rowid 列名，不接受自定义 tokenizer、外部 content 表等模块参数。RTree 第一列为整数 ID，随后是 1–5 对 min/max 坐标列，共 3、5、7、9 或 11 列，坐标采用 SQLite RTree 浮点存储规则。

ifNotExists: true 仅在同名虚拟表的模块和列定义一致时复用，否则报错。创建和删除各自使用独立事务；不能将原始虚拟表 DDL 放入 batch/migrate。创建后可以使用现有 query/execute/batch/migrate 对其查询和写入，失败及超时仍按原事务规则回滚。

SQLite defensive 模式保护模块影子表，禁止扩展直接改写、删除或重命名其内部存储；info().tables 只显示用户表和虚拟表本身。虚拟表改名不开放。删除前由扩展让用户确认，然后调用 await db.dropVirtualTable({name:'documents', ifExists:true})。
