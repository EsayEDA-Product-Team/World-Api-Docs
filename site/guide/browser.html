浏览器（BrowserAPI） ​

工作台 1.11.15 起提供 workbench.browser。扩展在 jlc-extension.json 中声明 "permissions": ["browser.open"]，即可用系统浏览器打开网页，或在桌面工作台内创建独立网页 Tab。

已有 SDK 工程执行 npm run sync 更新。运行时可调用 workbench.app.describe()，检查 browser.openExternal / browser.openTab 是否存在且 available。

页面自动化（当前 DEV） ​

新能力由宿主提供，无需安装自动化插件，也不额外下载浏览器或驱动。需升级到包含这些方法的工作台；SDK 同步只更新开发接口，不替代宿主更新。

json
{ "permissions": ["browser.open", "browser.automation", "browser.devtools"] }

只操作现有页面时可省略 browser.open；不用原始 DevTools 命令和事件时可省略 browser.devtools。后者必须同时具备 browser.automation。

类主要接口
BrowserAPIlistTabs()、getPage({tabId})
BrowserPageinfo()、goto()、reload()、goBack()、goForward()、waitForLoadState()、waitForURL()、content()、evaluate()、screenshot()、frames()、frame()、mouse()、keyboard()、close()
BrowserLocatornth()、count()、read()、click()、dblclick()、hover()、fill()、press()、selectOption()、setChecked()、scrollIntoView()、waitFor()
BrowserSubscriptionpollEvents()、unsubscribe()；由 page.subscribe() 创建
js
const methods = await workbench.app.describe();
if (!methods.methods.some(m => m.name === 'browser.getPage' && m.available)) {
  throw new Error('请更新工作台并为扩展声明 browser.automation');
}
const tabs = await workbench.browser.listTabs();
// 实际插件应让用户选定目标，而不是依赖“当前活动页”。
const selectedTab = tabs.find(tab => tab.url.startsWith('https://example.com/'));
if (!selectedTab) throw new Error('请先打开目标网页');
const page = await workbench.browser.getPage({ tabId: selectedTab.tabId });
await page.getByRole('textbox', { name: '搜索' }).fill('关键词');
await page.getByRole('button', { name: '搜索', exact: true }).click();
await page.waitForURL('*/results*', { match: 'glob', timeoutMs: 15000 });
const title = await page.locator('h1').read();
console.log(title.text);

目标范围是主浏览器 Tab 和本扩展创建的网页，不包含其他扩展网页、普通关联文档或工作台内部页面。页面对象绑定稳定的 tabId；后台调用不激活目标 Tab，也不回退到当前活动页面。Tab 已关闭或尚未初始化会报错。openTab() 创建壳层即返回，待其原生网页初始化后再获取和操作页面。

定位与输入 ​

locator() 接受 CSS 字符串或 {selector?,text?,role?,name?,exact?,nth?}。条件可组合；文本默认包含匹配并归一空白。getByText() 和 getByRole() 是相应快捷方法。角色名称支持常见原生控件、label 和 ARIA 属性，不等价于完整 Playwright 的无障碍算法。

每次操作都会重新定位元素，避免 DOM 重建导致旧节点失效。动作必须唯一匹配；多个匹配用更精确条件或 nth(0) 指定。点击等待可见、启用、稳定且命中点未遮挡，发出后不自动重复点击。填充适用于 input、textarea、contenteditable；selectOption() 适用于原生 select。

js
await page.locator('[data-item]').nth(1).click({ modifiers: ['Control'] });
await page.locator('#email').waitFor({ state: 'editable' });
await page.locator('#country').selectOption('CN');
await page.locator('#agree').setChecked(true);
await page.keyboard({ type: 'press', key: 'Escape' });
// Canvas 等内容可以按页面视口的 CSS 像素发送真实输入。
await page.mouse({ type: 'move', x: 100, y: 120 });
await page.mouse({ type: 'click', x: 100, y: 120 });

等待默认 10000 毫秒，timeoutMs: 0 表示立即检查，最大 60000。waitFor() 的状态包括 attached、detached、visible、hidden、enabled、editable。先前正在进行的同页动作可能排队；不同 Tab 各自执行。

脚本、截图与框架 ​

js
const value = await page.evaluate('return {title: document.title, input: arg};', { id: 1 });
const image = await page.screenshot({ format: 'png', fullPage: true });
await workbench.files.saveAs({ filename: 'page.png', data: image.base64, encoding: 'base64' });
const { frames } = await page.frames();
const child = frames.find(frame => frame.parentId);
if (child) console.log((await page.frame(child.id).content()).text);

evaluate(code,arg) 的 code 是异步函数体，使用 return 返回可 JSON 序列化的结果，arg 显式传参。content() 返回 {html,text,url,title}。截图返回 {base64,mimeType}，支持 png/jpeg/webp、fullPage 或 clip，后两者不可同时设置。

frame(id) 支持 info、content、evaluate、加载/URL 等待与元素操作；不可用框架明确报错，不回退顶层。导航、历史和截图需使用原页面对象。跨进程 iframe 取决于 WebView2 当前页面协议目标可见范围。info() 的 URL/标题对应框架，历史状态仍属于整个 Tab。

DevTools 命令和事件 ​

js
const subscription = await page.subscribe(['Network.responseReceived']);
try {
  await page.sendCommand('Network.enable');
  await page.reload();
  const batch = await subscription.pollEvents({ waitMs: 1000, limit: 100 });
  console.log(batch.events, batch.dropped);
} finally {
  await subscription.unsubscribe();
}

sendCommand() 覆盖页面级 Runtime、DOM、DOMSnapshot、Accessibility、Input、Page、CSS、Network、Fetch、Performance、Log、Debugger 等域。方法是否存在由系统 WebView2 版本决定。可用于网络响应体、打印 PDF、调试和请求拦截等高级操作；这不是完整的 Playwright 兼容层。

不开放 Browser、Target 等跨目标控制，或配置级 Cookie 读取/写入/删除、全配置缓存清理、任意本机路径文件上传。Runtime.disable 由宿主管理，避免破坏现有页面上下文追踪。高级脚本和网络能力能读取被授权目标页面的数据，插件需要按自身用途处理这些数据。不会向远端网站暴露宿主服务凭证。

订阅自动维护 cursor，队列有界，必须持续读取并检查 dropped。同一订阅不要并发消费。订阅属于创建它的扩展运行实例；页面关闭、实例结束、禁用、卸载时清理。插件启用 Fetch 拦截后应及时继续/取消请求，并在任务结束时 Fetch.disable；解除事件订阅不代表禁用协议域。

系统默认浏览器 ​

js
const result = await workbench.browser.openExternal({
  url: 'https://example.com/help',
});
console.log(result.opened, result.url);

调用系统默认浏览器，不需要 iframe 的弹窗权限，也不通过扩展页面的 window.open()。返回 {opened: true, url} 代表操作系统接受打开请求，不代表目标网页已经加载完成。系统浏览器启动失败会拒绝 Promise。

工作台内网页 Tab ​

js
const tab = await workbench.browser.openTab({
  url: 'https://example.com/help',
  title: '在线帮助',
});
console.log(tab.tabId, tab.url, tab.title);

每次调用创建并激活一个独立 Tab。title 可省略，默认“浏览器”；支持 1–120 字符。新 Tab 壳层创建后立即返回 {tabId, url, title}，网页异步加载；加载失败或超时在 Tab 内显示并支持重试。它使用桌面工作台现有的原生浏览器承载，支持既有关闭、浮动、吸附及 URL/标题恢复能力。

网页 Tab 打开后，扩展页面仍保留，可切回继续使用。扩展可保存 tabId 作为业务关联标识；从 1.11.32 起支持通过 tabId 定位原文或关闭本扩展的网页。tabId 是当前运行期标识；更新恢复后的 Tab 会获得新的标识。独立网页的内容、登录态及 SDK 对象不写入 Tab 恢复数据，只保存地址、身份和布局。网页使用工作台现有浏览器会话规则。

普通“关联文档”仍显示“文档”标签；SDK 打开的网页显示传入标题或默认“浏览器”。在网页浏览器中运行的工作台缺少原生网页承载时，Tab 会显示接口未就绪；该功能面向桌面工作台。

URL 与权限 ​

只接受完整 HTTP/HTTPS URL，不支持 file、javascript、data、mailto 等协议，不允许 URL 中带用户名或密码。URL 最长 16384 字符，空格等字符应先做 URL 编码。拒绝参数错误、未声明权限或扩展已禁用/卸载的调用。宿主不向打开的远端网页注入工作台服务 Token、Python 对象或扩展 SDK。

这两种方法分别属于 BrowserAPI 类的方法，既有 WindowAPI 继续负责显式会话的原型操作，PagesAPI 负责扩展包自己的页面。

侧栏、浮动窗口与引用定位（1.11.32） ​

在清单声明 "permissions": ["browser.open", "browser.control"]：

js
const page = await workbench.browser.openTab({
  url: 'https://example.com/document',
  title: '引用原文',
  placement: 'right', // tab（默认）、left、right、float
});
const found = await workbench.browser.locateText({
  tabId: page.tabId,
  text: '引用的原文',
  occurrence: 0, // 从 0 开始；1 表示第二次出现
  duration: 1800, // 闪烁高亮毫秒数；0 仅定位，最大 10000
  // blockId: '文档块ID', // 可选：先滚动到该块，并仅在该块内查找
});
if (!found.found) console.log(found.reason, found.matchCount);
// 使用结束时：await workbench.browser.closeTab({tabId: page.tabId});

左右侧栏和浮动网页与顶部扩展页面共存，打开或定位不会关掉扩展页面。浮动窗口复用既有原生浮动、吸附机制。关闭需要 browser.open；定位需要单独的 browser.control。同扩展的多个页面可以控制彼此创建的网页，不能定位或关闭其他扩展的网页、普通关联文档或主浏览器。

定位等待网页初次加载完成后搜索当前已渲染的主文档 DOM，支持跨行内元素和连续空白归一，保持原文和选择区不变。输入框、隐藏和标记为隐私的节点不参与搜索。成功返回 {found:true, matchCount, occurrence, rect:{x,y,width,height}}，坐标是目标网页视口 CSS 像素；失败返回 found:false 和 not-found、occurrence-out-of-range 或 block-not-found。网页未加载、已关闭或无权操作会拒绝 Promise。高亮在到时、下一次定位或页面离开时清理，不清除其他程序的高亮。

该接口不承诺搜索虚拟化文档中未渲染的正文，不穿透跨域 iframe，也不代替飞书 OpenAPI 获取文档。复用登录指 WebView2 的已有网站 Cookie/浏览器配置；工作台的飞书 OAuth 身份不会自动转换成飞书网站会话，网站仍可能要求首次登录。Cookie 与 OAuth Token 均不会返回扩展。
