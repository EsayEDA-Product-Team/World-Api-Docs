保存和恢复布局方案 ​

清单声明 ui.layout；保存方案还需要 storage。这些是正式宿主接口，无需操作 DOM 或注入 CSS。

内容读取修改
内置面板及已打开插件页签的停靠位置layout.get().panels[].placementlayout.movePanel({panel, placement})
浮窗位置panels[].x、ylayout.positionPanel({panel, x, y})
浮窗展开尺寸panels[].width、heightlayout.resizePanel({panel, width, height})
侧栏展开宽度，包括已收起侧栏sidebars[side].expandedWidthlayout.setSidebarWidth({side, width})
侧栏当前渲染宽度sidebars[side].width由展开宽度和收起状态决定
侧栏选中面板、展开/收起selectedPanel、collapsedlayout.activatePanel()、layout.setSidebarCollapsed()

get() 是异步接口，先 await 再读取字段。panels 现在同时包含 kind: 'builtin' 和 kind: 'extension'；后者还提供 extensionId、pageId、key 和 singleton。写接口统一接收 panels[].id，拥有 ui.layout 的布局插件可以管理其他插件已经打开的页面。普通 pages.* 接口仍只允许操作本插件页面。

位置为 left、right、float 或 tab，其中 tab 仅支持扩展页面，表示中央页签区域。这里的位置指停靠区域，不是页签排列顺序。浮窗 x/y 相对工作台主窗口客户区左上角，以 CSS 像素计；支持负坐标，宿主负责桌面 DPI 换算。停靠时设置坐标和尺寸会保留为下次浮动的值，不会自动浮动。浮窗收起内容时，快照仍返回展开高度。

js
const api = window.workbench;
await api.storage.set({ key: 'layout.default', value: await api.layout.get() });

恢复时先移动和调整面板，再恢复选择，最后收起侧栏。因为激活面板会展开它，不能先收起再激活。

js
const saved = await api.storage.get({ key: 'layout.default' });
if (!saved) throw new Error('尚未保存布局方案');
const current = await api.layout.get();
const available = new Set(current.panels.map((panel) => panel.id));
const actions = [];
const add = (method, params) => actions.push({ method, params });
for (const panel of saved.panels) {
  if (!available.has(panel.id)) {
    throw new Error('面板尚未打开：' + panel.title);
  }
  add('movePanel', { panel: panel.id, placement: panel.placement });
  add('resizePanel', { panel: panel.id, width: panel.width, height: panel.height });
  add('positionPanel', { panel: panel.id, x: panel.x, y: panel.y });
}
const selectedTab = saved.panels.find((panel) => panel.placement === 'tab' && panel.visible);
if (selectedTab && available.has(selectedTab.id)) {
  add('activatePanel', { panel: selectedTab.id });
}
for (const side of ['left', 'right']) {
  const sidebar = saved.sidebars[side];
  add('setSidebarWidth', { side, width: Math.round(sidebar.expandedWidth) });
  if (sidebar.selectedPanel && available.has(sidebar.selectedPanel)) {
    add('activatePanel', { panel: sidebar.selectedPanel });
  }
  add('setSidebarCollapsed', { side, collapsed: sidebar.collapsed });
}
const id = crypto.randomUUID();
// 在宿主可能搬移并重载本插件之前保存 ID。生产代码应防止同时发起两批。
await api.storage.set({ key: 'layout.pending', value: id });
await api.layout.apply({ id, actions });
// 返回 queued/running 不表示已经完成；使用下面的查询流程确认结果。

移动调用插件自身与重载恢复 ​

layout.apply 由宿主主窗口执行，所以移动布局插件自身到浮窗或返回侧栏/中央页签后，余下步骤仍继续。插件 iframe 可能重载；不能把操作放在插件自己的逐条 await 循环里。页面初始化时读取已保存的 ID，再通过 layout.operation 查询；查询不会启动或重复执行操作。

js
async function resumeLayout() {
  const id = await api.storage.get({ key: 'layout.pending' });
  if (!id) return null;
  let result;
  do {
    result = await api.layout.operation({ id });
    if (!result) {
      // 宿主重启、记录过期或未接受提交：先检查现有布局，不能自动重放。
      await api.storage.set({ key: 'layout.pending', value: null });
      throw new Error('操作记录不存在，请检查布局后重新应用');
    }
    if (result.status === 'queued' || result.status === 'running') {
      await new Promise((resolve) => setTimeout(resolve, 200));
    }
  } while (result.status === 'queued' || result.status === 'running');
  await api.storage.set({ key: 'layout.pending', value: null });
  if (result.status === 'failed') {
    throw new Error(`已完成 ${result.completed}/${result.total} 项：${result.error}`);
  }
  return result;
}
await resumeLayout();

每批 1–256 项，宿主批次串行执行；全部参数在提交时校验，目标存在性在执行前检查。单步失败会停止后续步骤，已发生的修改保留；失败步骤本身也可能产生部分变化，因此不是回滚事务。禁用或更新插件使原授权失效时，后续步骤停止。用户手动拖动和独立原子 API 不属于批次队列。

操作 ID 属于发起扩展；其他扩展查询不到。同 ID、同参数在记录保留期间只执行一次，同 ID 不同参数拒绝。宿主保留全部在途操作和最近 256 条完成记录，主窗口重启后清空。网络或消息回执失败时先查询状态，不要换新 ID 自动重试。

单实例插件面板 ID 跨重开稳定；多实例以实例 key 区分，重启自动恢复的实例保留 key，关闭后另建实例则产生新 ID。接口只枚举和操作当前已打开的插件页面，不自动启动已关闭或未安装的插件，不包含嵌入的外部程序窗口。未知或已关闭 ID 会报错。

侧栏宽度沿用现有覆盖规则：只覆盖本扩展持有的宽度；其他插件已占用时会报错，传 null 清除本扩展覆盖。覆盖在扩展禁用或工作台重载时清除；布局插件可从自己的持久存储读取方案后重新应用。collapsed 是用户布局偏好；某些工作模式暂时隐藏侧栏时，width 可能与该偏好不同。
