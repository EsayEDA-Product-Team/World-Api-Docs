扩展 HTTP / HTTPS 请求 ​

在清单 permissions 中声明 network，通过正式宿主接口 workbench.network.request() 发送请求。不要求插件自行调用浏览器 fetch，也不受页面 CORS 限制。

js
const response = await workbench.network.request({
  url: 'https://example.com/api/items',
  method: 'POST',
  headers: {Authorization: 'Bearer ' + ownToken},
  query: {tag: ['one', 'two'], enabled: true},
  json: {name: '示例'},
  responseType: 'json',
  timeoutMs: 25000
});
if (!response.ok) {
  console.log(response.status, response.body);
} else {
  console.log(response.body);
}

请求与响应 ​

  • url：HTTP/HTTPS 绝对地址，支持本机、内网和外网。Unicode 域名与路径会编码；URL 不可包含空白、控制字符或内嵌用户名密码。
  • method：GET（默认）、POST、PUT、PATCH、DELETE、HEAD、OPTIONS。
  • headers：字符串键值对象。可显式传入扩展自己的 Authorization、Cookie、自定义业务请求头；不能指定 Host、Content-Length、Transfer-Encoding、Connection、Proxy-Authorization 等传输控制头，不能注入 CR/LF。
  • query：基础值或基础值数组。数组生成重复参数，布尔值编码为 true/false，null 为空字符串，与 URL 已有查询参数拼接。
  • json：JSON 正文，自动设置 JSON Content-Type。也可以提供 body 字符串及 encoding: 'utf8' | 'base64'；不能同时提供 json 和 body。GET/HEAD 禁止正文。
  • responseType：json（默认）、text 或 base64。空 JSON 正文返回 null；非 JSON 页面应选择 text。text 按响应 charset 解码，未知 charset 回退 UTF-8。
  • timeoutMs：默认 25000，允许 1–60000 毫秒，包含重定向及响应读取。系统 DNS 解析仍受操作系统解析器的阻塞行为限制。
  • followRedirects：默认 true，最多跟随 10 次；false 时直接返回 3xx。

结果为 {url, status, statusText, ok, headers, body, responseType, bytes}。url 是最终地址，ok 表示状态码为 2xx。响应头名称小写，同名值用换行分隔。自动解压 gzip/deflate，bytes 是解压后实体字节数。JSON 中非有限数值会作为格式错误拒绝。

HTTP 4xx/5xx 本身不会使 Promise 失败，可以按 status 判断。网络、TLS、超时、解压失败，以及请求了 json 但正文不是有效 JSON 时，Promise 会失败。响应整体缓冲，无固定正文容量配额，受本机可用内存及桥接消息资源限制；目前不提供流式响应。

二进制上传和下载 ​

js
const download = await workbench.network.request({
  url: 'https://example.com/replay.html', responseType: 'base64'
});
if (download.ok) {
  await workbench.files.saveAs({
    filename: 'replay.html', encoding: 'base64', data: download.body
  });
}

await workbench.network.request({
  url: 'http://127.0.0.1:8000/upload', method: 'PUT',
  headers: {'Content-Type': 'image/gif'},
  body: gifBase64, encoding: 'base64', responseType: 'text'
});

身份和重定向 ​

请求不读取工作台 GitHub、飞书或浏览器登录态，不自动添加工作台的 Token、Cookie，也不持久化服务器返回的 Cookie。需要凭证时，由扩展显式提供自己的凭证。HTTPS 使用默认可信证书链及主机名校验，不提供关闭校验的选项。网络代理遵循 Python urllib 的系统代理设置，不允许扩展指定 Proxy-Authorization 请求头。

每次重定向重新验证目标协议。跨源（协议、主机或有效端口变化）时，只保留 Accept、Accept-Language、Accept-Encoding、User-Agent 和 Content-Type，剥离调用方的 Authorization、Cookie、自定义 API-Key 等其他请求头。301/302 的 POST 与 303 的非 HEAD 请求转为 GET，丢弃正文及内容相关请求头；307/308 保留方法和正文。若正文不应被转发，可使用 followRedirects=false 自行处理。

每个网络阶段和响应读取都会重新验证扩展会话及 network 权限；禁用、卸载、更新扩展或关闭会话后，未完成请求不再返回数据。已经到达远端服务器的写入无法因本地会话撤销而回滚。
