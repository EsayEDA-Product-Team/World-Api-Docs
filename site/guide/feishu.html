飞书 OAuth / OpenAPI ​

工作台 1.11.11 起，扩展可通过 workbench.feishu.status() 和 workbench.feishu.request() 直接调用飞书 JSON OpenAPI，复用工作台当前用户的 OAuth 登录。无需安装 CLI、飞书桌面客户端，也不需要扩展再次登录或保存用户 Token。

权限与版本 ​

扩展清单声明 "permissions": ["feishu.openapi"]。这是允许扩展代表当前飞书用户执行业务读写操作的宿主权限，并不增加飞书应用的 scope 或文档访问权限。用户仍需先在工作台登录飞书；缺少飞书 scope 或资源权限时，API 返回飞书错误信封，不能通过 SDK 绕过。

已有 SDK 工程执行 npm run sync 更新。运行时通过 workbench.app.describe() 检查 feishu.request 存在且 available。1.11.10 尚无此接口；1.11.9 的 CLI 方法 execute 与 feishu.cli 权限已经移除，不能沿用，应迁移到本文接口。

js
const api = await workbench.app.describe();
if (!api.methods.some(m => m.name === 'feishu.request' && m.available)) {
  throw Error('请更新工作台至 1.11.11 或更新版本，并声明 feishu.openapi 权限');
}
const user = await workbench.feishu.status();
if (!user.loggedIn) throw Error('请先在工作台登录飞书');

接口签名 ​

  • status() → {loggedIn, name, avatar}，不发起登录，不暴露应用密钥或用户凭证。
  • request({path, method?, query?, body?, timeoutMs?}) → {ok, httpStatus, body}。

path 必须是 /open-apis/业务域/...，不能传完整 URL、查询串或认证端点。method 默认 GET，支持 GET / POST / PUT / PATCH / DELETE。query 支持字符串、数字、布尔值及其数组，由宿主编码；body 为 JSON 对象或数组，不支持 GET body。不要自行传 Authorization、headers、Token 或 CLI 参数。

body 最多 1 MiB，响应最多 4 MiB；timeoutMs 默认 25000，范围 1000–60000。request() 仅支持 JSON，不支持二进制上传、下载或流式响应；1.11.12 起另提供下文的 uploadMedia() 进行 multipart 上传。宿主不自动重试写操作；超时后可能已经在远端生效，应先确认再重试。分页由扩展根据具体接口的 page_token / has_more 显式处理。

支持的业务域：docx、docs、docs_ai、drive、wiki、sheets、bitable、search、calendar、contact、task、im、mail、minutes、vc、okr、approval、whiteboard、attendance、slides。是否成功仍取决于接口本身和用户授权。

读取文档正文 ​

js
const response = await workbench.feishu.request({
  path: `/open-apis/docx/v1/documents/${documentId}/raw_content`,
});
if (!response.ok) throw Error(JSON.stringify(response.body));
const content = response.body.data.content;

documentId 是 docx 文档 ID，不是知识库节点 token。知识库链接先按下一节解析。

解析知识库节点、列出子节点 ​

js
const node = await workbench.feishu.request({
  path: '/open-apis/wiki/v2/spaces/get_node',
  query: {token: wikiNodeToken, obj_type: 'wiki'},
});
if (!node.ok) throw Error(JSON.stringify(node.body));
const {space_id, node_token, obj_token, obj_type} = node.body.data.node;
// obj_type 为 docx 时，obj_token 可作为上文 documentId。
const children = await workbench.feishu.request({
  path: `/open-apis/wiki/v2/spaces/${space_id}/nodes`,
  query: {parent_node_token: node_token, page_size: 50},
});

新建文档并写入文字 ​

js
const created = await workbench.feishu.request({
  path: '/open-apis/docx/v1/documents', method: 'POST',
  body: {title: '我的文档'}, // 如需指定文件夹，可按飞书接口加入 folder_token。
});
if (!created.ok) throw Error(JSON.stringify(created.body));
const id = created.body.data.document.document_id;
const written = await workbench.feishu.request({
  path: `/open-apis/docx/v1/documents/${id}/blocks/${id}/children`,
  method: 'POST', query: {document_revision_id: -1},
  body: {index: -1, children: [{block_type: 2,
    text: {elements: [{text_run: {content: '由扩展写入的正文'}}]}}]},
});
if (!written.ok) throw Error(JSON.stringify(written.body));

创建知识库子文档 ​

js
const created = await workbench.feishu.request({
  path: `/open-apis/wiki/v2/spaces/${spaceId}/nodes`, method: 'POST',
  body: {parent_node_token: parentNodeToken, obj_type: 'docx',
    node_type: 'origin', title: '新建子文档'},
});

返回节点中的 obj_token 是文档 ID，后续可调用 docx 正文接口；先检查 ok 再读取数据。

错误处理与边界 ​

飞书 HTTP/业务错误返回 ok: false，body 保留原始 code / msg / error 等 JSON 字段，方便定位 scope、ACL、参数或限流问题。宿主参数错误、未登录、网络超时、响应过大或非 JSON 会拒绝 Promise。扩展应同时处理两种情况，不要仅凭 Promise resolve 判断成功。账号在请求期间退出或切换，结果会被丢弃。

OAuth 是授权机制；上述 request 才是实际开放给扩展的调用接口。工作台自身云端库和扩展共用认证管理，用户凭证不会返回给扩展。业务示例按飞书标准 API 结构编写，本次仅做模拟回归，没有访问真实飞书账号或文档；具体资源 ID、应用 scope 和文档权限由接入者验证。

图片上传与图注（1.11.12 起） ​

SDK 新增 workbench.feishu.uploadMedia() 和 workbench.feishu.setImageCaption()，仍使用 feishu.openapi 权限和工作台 OAuth 登录，不依赖 CLI。request() 保持 JSON 请求；multipart 上传由专用方法负责。宿主不读取本机文件路径，扩展从剪贴板或文件选择器取得 Blob 后转成 Base64 传入。

方法与权限 ​

  • uploadMedia({documentId, blockId, fileName, contentBase64, parentType?, mimeType?, timeoutMs?})：上传至现有 docx 图片/附件块，返回 {ok,httpStatus,body}，素材 token 在 body.data.file_token。parentType 默认 docx_image，也支持 docx_file。contentBase64 不含 data:...;base64, 前缀，解码后为 1 字节至 20 MiB；size 由宿主计算，extra.drive_route_token 自动使用 documentId。默认超时 60 秒。不支持分片上传或二进制下载。
  • setImageCaption({documentId, blockId, fileToken, caption, timeoutMs?})：调用图片块的 replace_image，同时传素材 token 和 caption.content。caption 是纯文本（最多 64 KiB UTF-8），空字符串用于清空图注。fileToken 必填：修改已有图片图注时传原 token；插入新图片时传刚上传的 token。此方法不主动修改宽高或对齐，不适用于附件块。返回结构与 request 一致。

上传需要飞书应用开通并由用户授权 docs:document.media:upload（或官方列出的其他等价权限）；工作台登录授权请求已加入该 scope。已登录的旧账号需要在应用开通权限后重新授权，SDK 无法为现有令牌自动增加 scope。图注需要文档编辑权限（如 docx:document:write_only）及目标文档 ACL。权限不足仍返回飞书错误，不会自动重试。

完整图片关联示例 ​

先创建空图片块，再向这个块上传图片，最后绑定素材并写图注。parent_node 必须是图片块 ID，不能用 documentId 或知识库节点 token 替代；宿主会自动把 blockId 用作 parent_node。

js
function must(response) {
  if (!response.ok) throw Error(JSON.stringify(response.body));
  return response.body.data;
}
function blobBase64(blob) {
  return new Promise((resolve, reject) => {
    const reader = new FileReader();
    reader.onload = () => resolve(String(reader.result).split(',', 2)[1]);
    reader.onerror = () => reject(reader.error);
    reader.readAsDataURL(blob);
  });
}
// imageBlob 由插件的 paste 或文件选择处理取得。
// documentId 为 docx 文档 ID，parentBlockId 为文档内目标父块 ID。
const created = must(await workbench.feishu.request({
  path: `/open-apis/docx/v1/documents/${documentId}/blocks/${parentBlockId}/children`,
  method: 'POST', query: {document_revision_id: -1},
  body: {index: -1, children: [{block_type: 27, image: {}}]},
}));
const imageBlockId = created.children[0].block_id;
const media = must(await workbench.feishu.uploadMedia({
  documentId, blockId: imageBlockId,
  fileName: '截图.png', mimeType: imageBlob.type || 'application/octet-stream',
  contentBase64: await blobBase64(imageBlob),
}));
must(await workbench.feishu.setImageCaption({
  documentId, blockId: imageBlockId,
  fileToken: media.file_token, caption: '对应节点的图片说明',
}));

修改已有图注时，使用原 fileToken 和新 caption 调用 setImageCaption；传 caption: '' 清空。原 token 可从获取块接口的 body.data.block.image.token 取得。

上传成功不代表图片已经显示，必须检查最后绑定/图注请求也成功。分步失败时应保留本地同步状态和返回的 blockId/fileToken，恢复时继续未完成步骤，不能无条件重新创建图片块。是否只同步“与节点有连线的图片”由扩展在调用上传前判断，SDK 不读取扩展内部画布关系。

官方规范：上传素材、上传点与 extra、更新图片块与 caption。本次仅做模拟测试，未访问真实飞书数据。
