World API SDK ​

工作台扩展 API。

本文件是生产桥、SDK 类型和 API 文档共同使用的源码。 扩展运行时由宿主注入 workbench，不要在扩展包中复制桥接脚本。

APIDescription宿主实际注册的接口清单。
HTTPMethod支持的 HTTP 方法。
HTTPResponseType响应正文解码类型，默认 json；空 JSON 正文返回 null。
HTTPQueryValue查询参数基础值，布尔值编码为 true/false，null 编码为空字符串，数组展开为重复参数。
HTTPRequestOptions-
HTTPResponseHTTP 响应。url 为最终地址，ok 表示 2xx；header 名称小写，同名 header 用换行分隔。自动解压 gzip/deflate，bytes 是解压后正文长度；base64 正文也是解压后的实体内容。HTTP 4xx/5xx 正常返回；网络、TLS、超时、解压及正文格式错误会拒绝 Promise。
SQLiteValueSQLite 值；大整数用十进制字符串封装，BLOB 用纯 Base64。结果布尔值以整数 0/1 返回，超出 JS 安全范围的整数返回 integer 对象。
SQLiteParams位置参数或命名绑定参数；禁止拼接不可信输入到 SQL。
SQLiteStatement单条 SQL 及绑定值。
SQLiteOptions操作超时，默认 10000 毫秒，可设置为 1–60000，包含等待锁时间；长查询请分页。
SQLiteWriteResult本语句影响行数（包含触发器）和 INSERT 行 ID，其他语句为 null。
SQLiteInfo数据库信息；bytes 包含当前 WAL/SHM 文件，version 由 migrate 管理。
SQLiteVirtualModule可创建的内置模块；FTS5 默认 unicode61 分词，RTree 支持 1–5 维范围索引。不接受原生模块、外部 content 表或自定义 tokenizer。
SQLiteVirtualTableOptions虚拟表定义。表名和列名统一小写，只允许 1–64 位 ASCII 字母、数字、下划线，不能以数字开头，禁止 sqlite_、_world 前缀；列名不能重复或与表同名。FTS5 不允许 rank/rowid 列名。RTree columns 为 ID 列加 1–5 对 min/max 列，共 3、5、7、9 或 11 列。
BrowserTab工作台页面标识；文档种类仅包含本扩展创建的网页。
BrowserTimeout等待预算，默认 10000 毫秒，0 表示立即检查，最大 60000 毫秒。页面关闭、不可用或权限失效时拒绝 Promise。
BrowserNavigation导航等待条件，默认 load；none 只等待浏览器接受导航，不表示页面加载完成。
BrowserPageInfo当前页面状态；框架信息中的历史标志仍属于整个 Tab。
BrowserSelector可组合的元素条件。selector 是 CSS；text/name 默认包含匹配，exact=true 精确匹配；role/name 支持常见原生控件和显式 ARIA 属性，不等价于完整无障碍树算法。nth 从 0 开始；未指定时动作要求唯一匹配。定位器每次操作重新解析，不缓存失效节点。
BrowserRect网页 CSS 像素矩形。
BrowserElement元素状态。
BrowserClick点击选项；默认左键，等待可见、启用、位置稳定且命中点未被遮挡。
BrowserActionResult浏览器已执行输入或元素操作；不代表服务端业务保存成功，业务结果需继续等待或读取。
BrowserScreenshot截图选项；默认 png，quality 为 0–100，仅用于有损格式。fullPage 与 clip 不同时使用。
BrowserProtocolEvent页面 DevTools 事件。
BrowserEventBatch事件增量；cursor 用于下次读取，dropped 非零表示消费者落后造成事件丢失。
getWorkbench获取宿主已注入的根对象；不会安装第二份桥。

数据库 ​

ClassDescription
SQLiteAPI本扩展的 SQLite 数据库目录。需在清单声明 storage.sqlite。数据库名不接受路径，统一转为小写，支持 1–64 位英文字母、数字、下划线、短横线；拒绝 Windows 保留名称。扩展升级及卸载保留数据。
SQLiteDatabase由 sqlite.open 返回的数据库对象。WAL 模式，同一数据库操作串行化，SQL 在宿主后台执行，不阻塞界面。禁止外部路径、ATTACH/DETACH、设置 PRAGMA、自定义事务控制、原生扩展及临时表；虚拟表通过封装接口创建和删除，使用 batch/migrate 管理普通写入事务，不提供跨调用连接状态。FTS5 库允许只读 data_version PRAGMA 供模块内部同步，其他 PRAGMA 仍拒绝。关闭页面、禁用或升级扩展后句柄失效，再次打开即可恢复持久化数据。

浏览器 ​

ClassDescription
BrowserAPI网页打开与自动化入口；复用工作台原生浏览器，不向远端网页暴露宿主或扩展凭证。
BrowserPage工作台原生 WebView2 页面。浏览器行为通过宿主的页面协议与真实输入通道执行，不附带另一套浏览器或驱动。框选编辑中的页面可能隔离用户输入；自动化前由调用方结束不兼容的编辑任务。每个对象固定到 tabId，不隐式切换活动页。
BrowserLocator页面元素定位器。每次动作重新查询目标，支持延迟出现及 DOM 重建；多匹配需使用 nth 明确目标。普通点击、悬停和输入使用浏览器原生输入协议；selectOption 使用原生 select 的值及 input/change 事件，不调用网页的 element.click。
BrowserSubscription目标页面的 DevTools 事件订阅。使用结束后 unsubscribe；可在插件自管循环中读取网络、控制台或 Fetch 拦截事件。需同时声明 browser.automation 与 browser.devtools。

网络 ​

ClassDescription
NetworkAPI经工作台宿主执行的 HTTP/HTTPS 请求；不受浏览器 CORS 限制，需清单声明 network 权限。每次请求独立，不共享工作台登录态，不持久化服务器 Cookie。HTTPS 保持系统默认的证书和主机名校验，不开放关闭校验的选项。响应整体缓冲，无固定正文容量配额，受本机内存和消息传输资源约束；不提供流式响应。

飞书 ​

ClassDescription
FeishuAPI飞书 OpenAPI；复用工作台 OAuth 登录，无需 CLI，不向扩展返回凭证。
