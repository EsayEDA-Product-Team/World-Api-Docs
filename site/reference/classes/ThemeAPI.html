World API SDK / ThemeAPI

ThemeAPI class ​

签名 ​

ts
class ThemeAPI

备注 ​

全局明暗与语义变量。宿主自动将 data-theme、color-scheme 和 --world-* 变量同步到所有扩展文档及独立浮窗。插件直接使用 CSS 变量；自有硬编码颜色仍需自行迁移。用户偏好跨重启保存。

方法 ​

方法名权限描述
get()无需额外权限读取偏好、已解析模式和主题变量。
tokens()无需额外权限枚举全部官方语义变量及明暗默认值。
set()ui.theme修改并保存全局主题；省略字段保持原值，变量值 null 撤销该项覆盖。变更立即同步，不重载插件。system 跟随系统变化。
onDidChange()无需额外权限订阅主题变化，包含系统模式变化；返回取消订阅函数。注册后会交付当前已接收的主题。API 与 CSS 变量由同一条事件同步。

get() ​

ts
get(): Promise<ThemeState>;

读取偏好、已解析模式和主题变量。

返回值 ​

Promise<ThemeState>

当前全局主题。

tokens() ​

ts
tokens(): Promise<ThemeToken[]>;

枚举全部官方语义变量及明暗默认值。

返回值 ​

Promise<ThemeToken[]>

变量定义。

set() ​

ts
set(params): Promise<ThemeState>;

修改并保存全局主题；省略字段保持原值，变量值 null 撤销该项覆盖。变更立即同步，不重载插件。system 跟随系统变化。

参数 ​

ParameterTypeDescription
params{ mode?: ThemeMode; overrides?: Record<string, string | null>; }仅支持 tokens() 中列出的语义变量，值需符合其 CSS 属性类型，不加载外部资源。覆盖适用于明暗两种模式。
params.mode?ThemeMode-
params.overrides?Record<string, string | null>-

返回值 ​

Promise<ThemeState>

生效的全局主题。

所需权限 ​

ui.theme

示例 ​

ts
await workbench.theme.set({mode:'dark'});
