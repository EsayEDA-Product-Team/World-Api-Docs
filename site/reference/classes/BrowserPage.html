BrowserPage class ​

签名 ​

ts
class BrowserPage

备注 ​

工作台原生 WebView2 页面。浏览器行为通过宿主的页面协议与真实输入通道执行，不附带另一套浏览器或驱动。框选编辑中的页面可能隔离用户输入；自动化前由调用方结束不兼容的编辑任务。每个对象固定到 tabId，不隐式切换活动页。

属性 ​

PropertyModifierTypeDescription
tabIdreadonlystring稳定的工作台 Tab 标识。
kindreadonly"browser" | "document"页面种类。

方法 ​

方法名权限描述

goto()browser.automation导航指定 Tab，不切换工作台当前 Tab；只接受 HTTP/HTTPS。
reload()browser.automation刷新指定页面。
goBack()browser.automation返回当前页面的上一条历史记录。

evaluate() ​

ts
evaluate(
   code,
   arg?,
   options?
): Promise<any>;

在目标页面执行异步 JS 函数体。使用 arg 接收显式 JSON 参数，并 return JSON 可序列化结果；网页脚本异常会拒绝 Promise。

参数 ​

ParameterTypeDefault valueDescription

options?BrowserTimeout{}等待预算。超时不会保证撤销已经发生的页面副作用。

返回值 ​

Promise<any>

所需权限 ​

browser.automation

示例 ​
