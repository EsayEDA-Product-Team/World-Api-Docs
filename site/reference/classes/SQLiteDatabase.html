SQLiteDatabase class ​

签名 ​

ts
class SQLiteDatabase

备注 ​

由 sqlite.open 返回的数据库对象。WAL 模式，同一数据库操作串行化，SQL 在宿主后台执行，不阻塞界面。禁止外部路径、ATTACH/DETACH、设置 PRAGMA、自定义事务控制、原生扩展及临时表；虚拟表通过封装接口创建和删除，使用 batch/migrate 管理普通写入事务，不提供跨调用连接状态。FTS5 库允许只读 data_version PRAGMA 供模块内部同步，其他 PRAGMA 仍拒绝。关闭页面、禁用或升级扩展后句柄失效，再次打开即可恢复持久化数据。

属性 ​

PropertyModifierTypeDescription
idreadonlystring会话句柄；不能用于其他扩展或会话。
namereadonlystring数据库名。

方法 ​

方法名权限描述

createVirtualTable()storage.sqlite使用受控定义原子创建 FTS5 全文表或 RTree 空间索引。同名对象存在时默认报错；ifNotExists=true 仅在模块和列定义完全一致时复用。表定义及影子表由宿主管理，原始 CREATE VIRTUAL TABLE SQL 仍不可用。
dropVirtualTable()storage.sqlite原子删除受支持的虚拟表及其影子表，不可用于普通表。FTS5/RTree 内部存储不允许通过普通 SQL 直接修改、删除或改名；此方法会等待同库操作完成。删除前由扩展让用户确认。

close()storage.sqlite等待当前操作完成后关闭本会话句柄；不会删除文件，不影响其他会话句柄。重复关闭或使用已失效句柄时报错。

virtualTableModules() ​

ts
virtualTableModules(options?): Promise<{
  fts5: boolean;
  rtree: boolean;

createVirtualTable() ​

ts
createVirtualTable(params): Promise<{
  name: string;
  module: SQLiteVirtualModule;
  created: boolean;
}>;

使用受控定义原子创建 FTS5 全文表或 RTree 空间索引。同名对象存在时默认报错；ifNotExists=true 仅在模块和列定义完全一致时复用。表定义及影子表由宿主管理，原始 CREATE VIRTUAL TABLE SQL 仍不可用。

参数 ​

ParameterTypeDescription
paramsSQLiteVirtualTableOptions表名、模块、列和超时；不接受任意 SQL 定义或模块参数。

返回值 ​

Promise<{ name: string; module: SQLiteVirtualModule; created: boolean; }>

规范化后的表名、模块及本次是否创建。

所需权限 ​

storage.sqlite

Examples ​

ts
await db.createVirtualTable({name:'documents',module:'fts5',columns:['title','body'],ifNotExists:true});
ts
await db.createVirtualTable({name:'regions',module:'rtree',columns:['id','min_x','max_x','min_y','max_y']});

migrate(params): Promise<{

所需权限 ​
