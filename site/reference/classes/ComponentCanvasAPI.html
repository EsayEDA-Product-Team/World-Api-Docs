ComponentCanvasAPI class ​

签名 ​

ts
class ComponentCanvasAPI

备注 ​

查看当前组件画布并执行图层选择和编辑历史操作。

方法 ​

方法名权限描述
onChanged()无需额外权限监听组件画布变化。收到通知后重新读取快照。
snapshot()components.read获取当前编辑文档的图层树与选中状态。无组件文档时返回空快照。
select()window.execute选择活动文档中的图层。layerId 为 null 时选中整个组件。
undo()components.write撤销活动文档的最近一次编辑。
redo()components.write重做活动文档中刚撤销的编辑。
dropLayer()components.write将图层交给有效的编辑目标。没有目标时不改变画布。
onLayerDropped()无需额外权限监听一个图层被拖入当前检查器，坐标以该检查器页面的视口为准。
inspect()components.read读取选中元素、交互草稿及可编辑属性。画布未打开或仍在加载时返回 null。
editProperty()components.write修改一个图层属性。支持 x、y、width、height、label、text、value、src、color、backgroundColor、fontSize、borderRadius 和 opacity。
removeLayer()components.write删除活动文档中的普通图层。
resizeGroup()components.write调整当前选中组合的整体宽高。
ungroup()components.write拆开当前选中组合。
stageInteractions()components.write更新活动文档的未保存交互草稿。expectedRevision 必须与读取时的版本相同。
acceptLayerDrop()components.write把刚拖入检查器的图层设置为交互动作的目标。凭证由 onLayerDropped 事件提供，只能使用一次。
onLogChanged()无需额外权限监听当前组件动作日志变化，并用 document 读取新内容。
onSaveRequested()无需额外权限监听宿主请求组件工具栏保存当前文档。
onFlushRequested()无需额外权限监听检查器字段提交请求。提交并校验字段后调用 acknowledgeFlush。
document()components.read获取当前组件文档的保存、预览与动作记录状态。
captureDocument()components.write捕获要保存的活动组件正文，等待打开的检查器完成字段编辑。
applySavedDocument()components.write核对保存记录与捕获正文，再将存储标识、版本和元数据回填至编辑文档。
discardCapture()components.write放弃同一沙箱的未使用保存凭证。
acknowledgeFlush()window.execute确认当前检查器已提交字段，并报告表单是否有效。
setPreview()window.execute切换活动文档的交互预览。
toggleInspector()window.execute打开或收起活动文档的检查器。
presentToolbar()window.execute在当前工作区临时放大或还原被选中的组件工具栏页面，供表单显示。
openAxure()window.execute在 Axure 提供者中打开活动组件的导入或导出。导出需先保存组件。
onMenuRequested()无需额外权限接收工作台画布右键操作。提供者可在五秒内调用 presentMenu 提供菜单项。
onMenuSelected()无需额外权限接收用户在画布菜单中选择的操作标识。
onResizeRequested()无需额外权限接收用户通过画布快捷键发出的尺寸编辑请求。
requestSave()window.execute请当前组件工具栏执行保存流程。
presentMenu()window.execute在请求的位置展示组件画布菜单。凭证绑定触发请求的工具栏会话。
groupSelection()components.write组合当前选区，或拆开所选组合。
resizeSelection()components.write根据尺寸请求的凭证调整原选区整体宽高。
