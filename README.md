# World API 公共文档

阅读入口：https://esayeda-product-team.github.io/World-Api-Docs/

本站使用 Vite + Vue（VitePress），提供中文指南、类与方法导航、页内索引和本地搜索。

本仓库仅接收私有 SDK 仓库通过完整 CI 验证的静态文档产物。SDK 和工作台源码保持私有。请勿在此修改生成的 `site/`；下一次发布会覆盖它。文档更新应提交到私有 SDK 源仓库，经 CI → CD 自动同步。

部署来源可在站点 `provenance.json` 查看。公开仓库 Pages 工作流只部署 `site/`。
